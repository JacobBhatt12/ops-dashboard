# Product

## Register

product

## Users

The owner of Thera Web Design uses this private local dashboard to choose client contacts and send website-care reports without editing code.

## Product Purpose

Make recipient selection and one-time management email sends clear, fast, and difficult to misconfigure while preserving the existing Canva-inspired email design.

## Brand Personality

Assured, polished, and direct. The interface should feel like a dependable internal business tool that belongs beside the existing TheraWeb materials.

## Anti-references

Avoid novelty controls and visual changes that compete with or replace the saved Website Care
email design. (Superseded 2026-09-14: this used to also rule out an analytics-dashboard look
with stat cards; the owner asked for exactly that — a sidebar + stat-tile shell modeled on a
shadcn/ui admin template — so that's now the house style. Keep stat tiles restrained: real
derived numbers only, no fabricated trends, one accent color used sparingly.)

## Design Principles

1. Make the recipient list the main decision surface.
2. Show the exact scope before a send starts.
3. Preserve familiar controls and plain-language status feedback.
4. Keep the Canva-inspired email template as the source of truth.
5. Prefer a focused local workflow over configuration complexity.

## Accessibility & Inclusion

Target WCAG 2.2 AA contrast and focus visibility. Support keyboard navigation, readable type, touch-friendly targets, status announcements, and reduced motion.
